# Real-time High-Frequency Monitoring Dashboard

Vue 3 + TypeScript + Vite + ECharts + TailwindCSS.

## Phase 1

Only the project foundation is initialized in this phase. Business features such as WebSocket data streams, Web Workers, ECharts dashboards, and virtualized lists are intentionally not implemented yet.

## Install

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
